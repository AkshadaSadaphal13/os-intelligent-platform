# 🖥️ Intelligent OS Analytics & Resource Management Platform

An end-to-end Python platform combining real-time Operating System monitoring, classical OS algorithm simulations, log analytics, and machine-learning-driven resource allocation.

## 🚀 Key Features
- **Live Process Monitoring:** Real-time process tracking & system metrics via `psutil`.
- **CPU Scheduler Engine:** Comparative analysis of SJF, FCFS, and Round-Robin.
- **Memory Prediction:** ML model predicting memory usage spikes.
- **Deadlock Detection:** Safety state evaluation using Banker's Algorithm.
- **Page Replacement Simulator:** Visual performance tracking for FIFO, LRU, and Optimal algorithms.
- **Log Parsing:** Regex-driven error and anomaly extraction.
- **AI Resource Allocation:** Decision-tree-based process throttling recommendations.
